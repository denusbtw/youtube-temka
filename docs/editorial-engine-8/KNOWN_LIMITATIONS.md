# Known Limitations & Honest Blockers (Factory 8.0)

1. **Multi-Source Human-Annotated Holdout Dataset (`BLOCKED`)**: Only one full-length real gaming source (`full-progressive.mp4`, 617.906 s GTA compilation) plus local short speech/synthetic fixtures exist locally. A 15–20 source independently annotated cross-genre holdout set (racing, shooter, podcast, livestreams, no-highlight sources) is not locally available; `Editorial Precision@3 >= 70%` on a holdout set cannot be claimed until external authorized media and human labels are supplied.
2. **Human Editorial Approval (`PENDING_HUMAN_REVIEW`)**: Although engineering inspection of all 3 rendered 6-frame storyboards confirmed 0% end-card/title-card contamination and 0% unrelated-scene merges across `554.12–598.35 s`, `445.50–478.50 s`, and `413.00–445.50 s`, final editorial approval requires explicit human reviewer sign-off via the Editorial Review UI / feedback API.
3. **1.7B Local VLM Caption Nuance**: `qwen3-vl:2b-instruct` accurately identifies format breaks (100% recall), scene continuity, and major objects (`white pickup truck`, `yellow pickup truck on highway`), but can occasionally mislabel visually small vehicles (e.g. describing a pink mobility scooter as a `"red lawn mower"`). All visual summaries remain explicitly marked for operator review before publishing.
4. **Consumer 4 GB VRAM Ceiling**: Concurrent Whisper + VLM + NVENC would exceed 4 GB VRAM. All heavy GPU workloads remain serialized under `HEAVY_LOCK`, bounded via single-composite-grid `num_ctx=2048` (`2673–2736 MiB` peak VRAM), and gracefully degrade to CPU / deterministic CV graph if VRAM is constrained or Ollama is unavailable.
5. **Optional Third-Party Vision/OCR Packages**: `transnetv2_pytorch`, `scenedetect`, and `rapidocr_onnxruntime` are intentionally not pinned in the lean `requirements-factory.lock` Docker image; deterministic PyAV/OpenCV shot and text-band detectors run out of the box, with optional adapters activating automatically if installed.
6. **Rights & Monetization Policy**: Automated clipping, captions, hooks, and attribution do not grant copyright permission or YouTube monetization eligibility for third-party content. Operator rights confirmation, reused-content warnings, and disabled automatic public publishing remain strictly enforced.
