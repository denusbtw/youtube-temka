# Phase 0 — Upstream & Legacy OpenShorts Reuse Audit

## License Compliance Summary
- **Active Factory base (`mutonby/openshorts`, MIT core)**: Permissive MIT. Commercial `cloud/` directory is strictly excluded from `deploy/factory.Dockerfile` and never imported by `factory/`.
- **`ColinGPT9/clips-studio` (Clips Kitty)**: **AGPL-3.0**. Do NOT copy implementation code. Clean-room conceptual design only (gaming genre profiles, multimodal signal fusion, HUD/banner awareness, reaction lag).
- **`osbytes/reelsaw`**: **AGPL-3.0**. Do NOT copy implementation code. Clean-room implementation of Map → Pool → Verify → Score → Pairwise Rank (with A/B order swap position-bias mitigation) and decision logging.
- **`artbyjazi/autoclip`**: **MIT**. Inspires resumable per-stage file-artifact checkpoints (`source-evidence-v1.json`, `vlm-cache.json`) and local-first architecture.
- **`ghost1412/shortsflow`**, **`modelscope/FunClip`**, **`Anil-matcha/AI-Youtube-Shorts-Generator`**, **`AnIntellectualBeing/GTA-Auto-Clipper`**: **MIT** (with separate model weight / Remotion commercial licenses noted). Studied for gaming highlight heuristics and caption pacing; no external runtime dependencies imported into `requirements-factory.lock`.
