# Known limitations
EDITORIAL QUALITY NOT YET VERIFIED. The real benchmark lacks human annotations. Visual features detect possible shot changes, not actual events. Remote visual analysis remains coarse. Only local input receives fine follow-up inspection, capped at six intervals and 32 seeks each. There is no optional visual-semantic provider. The current metadata generator uses templates for supported context and existing extractive behavior for generic input. Preview shares geometry, not exact FFmpeg text rasterization. File deletion and source-media catalog work remains incomplete.
