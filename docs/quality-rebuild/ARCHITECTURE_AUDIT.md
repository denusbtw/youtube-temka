# Architecture audit
The deployed entry point is FastAPI controller plus local queue worker. The live path is factory/pipeline.py → Whisper chunks → factory/visual_analysis.py and factory/shorts.py → factory/media.py FFmpeg → metadata/editorial validation. React is served by the Factory Vite bundle. Worker leases and Drive ledgers live in SQLite.
The legacy main.py invokes scene_detection.py (TransNetV2 or PySceneDetect) and gemini_worker.py (external visual inference). Its clip_selection.py implements separate ranking/window logic. None of these are in the controller Dockerfile source allowlist. The full-frame legacy scene extraction and externally uploaded Gemini flow are poor defaults for this bounded local worker. Reuse algorithmic ideas, not the external uploads or a second pipeline.
Factory framing already uses OpenCV Haar faces, smoothing and a reused MIT FFmpeg trajectory function. Gameplay picture-in-picture faces can be misleading. Remotion is present for legacy creative workflows; FFmpeg owns the deployed Factory render path. Whisper, Ollama, timeline manifests and audio edit checkpoints already have independent runtime responsibilities.
